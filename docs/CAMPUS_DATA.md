# 校园资料来源与整理范围

示例选取了本地 RAG 知识库中的《选课》《开学英语分级》两份 2024 年山东大学（威海）材料，共 13 段。
只保存原文摘录，不分发完整 DOCX，不收录联系人、电话、邮箱或学生名单。
来源清单与摘录一同打包在 `workspace_agent/fixtures/campus`，安装后也可以运行 `init-demo --scenario campus`。

manifest 中 `source_sha256` 对应原始 DOCX，`excerpt_sha256` 对应仓库 Markdown 的 UTF-8 字节。
`paragraphs.index` 是 DOCX 内所有 `w:p` 的一基序号，包含空段和表格段落。
测试验证内置摘录与 manifest 一致；运行时的文件读取工具另外返回当前材料的 SHA-256，产物保留该值。
如果工作区材料被修改，产物与指纹随实际读取结果变化，不会继续声称和内置摘录一致。
运行时不重新打开原 DOCX，也不把摘录里的段落标记当成独立真实性证明。

`CampusDeskMockModel` 的固定步骤是列目录、搜索 `2024`、读取命中的 Markdown、生成索引。
只整理 `materials/` 内最多 8 份匹配文件；搜索被截断、存在跳过文件或没有成功完整读取时不提议写入。
它从工具 observation 取正文，没有模型内置的材料副本或旁路文件访问。
输出按“选课时间、考试时间、参加对象、证件、课程号、附件”等关键词摘录完整原文，无法理解所有通知格式。

材料说明中的年份、校区来自已核对的来源快照。校园演示不查询最新政策，不安排当前考试，
也不根据学生个人信息作资格判断。学校材料权利归原作者；代码 MIT 许可不授予原文再分发权。
