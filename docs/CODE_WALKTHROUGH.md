# 代码导览

## 核心路径

按 [`tools.py`](../src/workspace_agent/tools.py) → [`sandbox.py`](../src/workspace_agent/sandbox.py) →
[`models.py`](../src/workspace_agent/models.py) → [`runtime.py`](../src/workspace_agent/runtime.py) →
[`store.py`](../src/workspace_agent/store.py) 阅读工具契约、权限、模型协议、执行循环与持久化。
[`campus.py`](../src/workspace_agent/campus.py) 在同一套循环上实现校园资料整理，
[`ui.py`](../src/workspace_agent/ui.py) 只读取保存的状态，不执行或恢复任务。

## 工具调用与执行顺序

模型返回函数名、调用 ID 和 JSON 参数，由 `ToolDispatcher` 校验并执行。
白名单包含六个工具，参数采用严格类型并禁止额外字段；字符串形式的数字、布尔值不会被自动接受。
每次执行前保存调用意图，执行后才保存 observation，下一轮模型只能读取已经记录的结果。

同一响应中的多个工具顺序执行。重复调用 ID 被拒绝，重复工具与参数受循环检测约束。
文件正文始终是 tool 数据，不能改变系统权限。离线模型按 observation 选择固定分支，不能解释任意自然语言目标。

## 沙盒与写入批准

授权根目录必须明确存在。沙盒固定目录描述符，逐组件使用 `dir_fd` 和 `O_NOFOLLOW`，
拒绝符号链接、多重硬链接、特殊文件和敏感路径；操作前后核对根目录、祖先位置与 inode。
同一 OS 身份的恶意原生进程仍可能制造竞态，应用沙盒不能替代 OS 隔离。

默认写入只返回预览。`--approve-writes` 授予当前目录内的写能力；覆盖还需要
操作者指定 `--allow-overwrite`，并在工具参数中提供 `overwrite=true`。
写入成功后重新打开文件核对内容与 SHA-256。todo 只能修改格式正确的保留状态文件。

## 中断与预算

SQLite 原子保存 JSON 快照，不提供数据库与文件之间的跨资源事务。
`recover` 将遗留运行标记为 `interrupted`，不把缺少结果解释成尚未执行，也不自动重放副作用。
强制终止可能留下部分文件，恢复时需要核对实际产物。

模型超时或可重试错误在预算允许时最多重试一次。工具没有通用自动重试；
越权、权限拒绝、覆盖拒绝和写超时终止运行，只读错误可交回下一轮模型处理。
轮数、工具数、总时间、模型超时和 token 计数分别受限。

请求前使用消息与 Schema 的 UTF-8 字节数估算，并预留输出额度；有 provider usage 时优先记录。
缺失 usage 或请求结果不确定时明确记为估算。这些限制抑制失控调用，不等同于账单级费用封顶。
工具进程使用 Linux / WSL 的 fork 后端，原生 Windows 需要独立实现。

## MCP 与结果视图

MCP stdio Server 与原生派发共用 Pydantic Schema 和 `ToolDispatcher`。
客户端只启动固定 Python 模块，不接受任意可执行命令；stdout 留给协议，模型密钥不传给工具进程。
`mcp-demo` 通过独立进程比较列目录、读取、搜索、写预览及拒绝路径。

TUI 直接读取计划、预算、工具事件、错误和最终结果。只有写工具与证据中的路径、哈希、
存在状态和验证标记全部一致，才列入已核验产物；模型文字不能构成写入证据。
终端控制字符会被转义，Rich 标记按普通内容处理。

## 校园资料整理

校园模型只从本轮搜索和读取结果生成索引，没有旁路文件访问。
搜索被截断、跳过文件、来源超过数量限制或无法完整读取时停止生成。
输出保留学院例外、办事要求与读取指纹；哈希用于确认字节一致，不能证明材料当前适用或结论正确。
范围与来源见[校园资料说明](CAMPUS_DATA.md)，验证命令见[演示说明](DEMO.md)。
